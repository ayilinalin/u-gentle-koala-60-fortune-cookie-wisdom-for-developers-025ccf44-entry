One original fortune-cookie line for a software developer, at most 120 characters, for make.fun's "Fortune Cookie Wisdom for Developers" bounty. The program writes the line to `/output/entry.txt`.

## The line

> Your estimates are not lies; they are fortunes told before the future has had its say.

## Why this line

Every developer has watched an estimate turn out wrong, and the tired senior engineer knows the estimate was never a lie — it was a prediction made before the future had spoken. The line turns that truth with a fortune cookie's own trick: it calls the estimate itself a fortune, so the cookie is quietly about fortune-telling. One balanced sentence, lands in a single breath, and the second read is the reward.

## Run it

```sh
python3 main.py
```
